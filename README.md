# Eloquent JavaScript – Exercises & Practice

This repository contains my solutions and experiments based on the book  
**“Eloquent JavaScript” by Marijn Haverbeke**.

The goal of this repo is not just to complete exercises, but to **build a solid understanding of JavaScript fundamentals**, idioms, and problem-solving patterns — especially from the perspective of someone coming from a strong Python background.

---

## 📚 What’s inside

- Solutions to selected exercises and examples from *Eloquent JavaScript*
- Small experiments and variations to better understand concepts
- Clean, readable JavaScript focused on clarity over cleverness

Topics covered include (among others):

- Variables, control flow, and functions
- Higher-order functions and callbacks
- Data structures (arrays, objects, maps)
- Basic functional programming concepts
- Gradual exposure to JavaScript-specific patterns and quirks

---

## 🎯 Purpose of this repository

This repository serves as:

- A **learning log** while working through *Eloquent JavaScript*
- A way to build **JavaScript muscle memory**
- A reference for comparing **Python vs. JavaScript approaches**
- Proof of **consistent, hands-on practice**, not just course completion

The focus is on understanding *why* something works in JavaScript, not just making it pass.
